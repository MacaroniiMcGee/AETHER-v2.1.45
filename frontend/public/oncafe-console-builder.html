OnCafe Console Builder

Generate it here, run it in the app's console.

This tool builds small JavaScript files that drive the OnCafe QA platform for you — bulk-creating and deleting reports, automations, identities, access levels, cardholder groups and more. You configure an action, copy the generated script, and paste it into your browser's DevTools console on the OnCafe tab. The script captures your login token automatically and runs.

1

Pick an action

Choose a task from the menu on the left (e.g. Create access levels). Groups are collapsed — click a group to expand it, then click an action to open its panel.

2

Configure & copy

Set names, counts and options. Some actions ask you to paste a scanned list (doors, access levels, cardholders) first — follow the inline Step 1 / Step 2 blocks. Then press Copy script (or Download .js).

3

Open the OnCafe tab & its console

On the running OnCafe app tab, open DevTools (F12, or Cmd+Option+I) and click the Console tab. If you see a paste warning, type allow pasting once and press Enter.

4

Paste & trigger

Paste the script and press Enter. It waits for your auth token — trigger one API call by opening or refreshing any page in the app. The script then runs automatically and logs ✓ per item, ending with a Done summary (and an error table if anything failed).

⚠Run scripts only on the OnCafe QA app tab (oncafe.hanwhavision.cloud). They act with your logged-in permissions against real QA data. Each script is read-only until it captures your token, and you can close the tab to stop it.

…or pick anything from the left menu to begin.
